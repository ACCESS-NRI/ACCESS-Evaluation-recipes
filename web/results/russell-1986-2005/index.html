16 diagnostic groups
35 plots

OM3: 14 groups. CM3: 8 groups. The run produced 107 numerical products. Availability varies by diagnostic.

CM3 is a present-day control: 1986–2005 denotes model years. OM3 is a forced-ocean experiment. These experiments have different forcing from the CMIP historical runs.

How these results were produced

ACCESS output → MOPPy CMORisation → ESMValCore preprocessing → Russell diagnostics → joint model comparison.

This run reused audited full-period CMORised outputs and preprocessing caches. The updated diagnostic scripts were rerun on Gadi analysis3-26.10. Local adaptations handled native cell polygons, hemisphere masks, display labels and exclusion of the ACCESS experiments from regression fits. MOPPy CMORisation was not repeated for this diagnostic run.

All 85 CMIP6/CMIP7 baseline comparisons passed for scientific values, dtypes, masks, coordinates and units, subject to the Figure 9 plotting-range exception below. Generated provenance attributes were checked separately. The 182 input files passed identity, time-coverage and size/mtime checks.

Figure 9 fits use the four selected CMIP6 models only, with OM3/CM3 added as comparison points. The updated CMIP7 recipe omits these fits. Saved regression lines may extend over the wider plotting range; their coefficients were independently checked against the CMIP6 points.

The inherited climatological transport and staggered-grid approximations, native front thresholds of 4.15/2.15°C and March sea-ice season were retained. Numerical parity establishes implementation consistency; it does not independently establish the accuracy of these scientific methods.
